# ⚡ বিদ্যুৎ বন্ধু — প্রিপেইড মিটারের AI এজেন্ট

DESCO/DPDC প্রিপেইড মিটারের ব্যালেন্স, খরচ আর বিল নিয়মিত দেখে রাখে। বাংলায় প্রশ্নের উত্তর দেয়, আর সমস্যা হলে টেলিগ্রামে জানিয়ে দেয়।

## যা যা করে
| ফিচার | বিবরণ |
|---|---|
| 📊 লাইভ ড্যাশবোর্ড | ব্যালেন্স, দৈনিক/মাসিক ইউনিট, লোড বা খরচের হার, রিচার্জ হিস্ট্রি |
| 🤖 AI চ্যাট | বাংলা, Banglish বা ইংরেজিতে প্রশ্ন। LLM টুল-কলিং করে আসল ডেটা থেকে উত্তর দেয় |
| 🧾 বিল হিসাব | BERC ট্যারিফ (জুন ২০২৬) অনুযায়ী স্ল্যাব, ডিমান্ড চার্জ, মিটার ভাড়া, রিবেট আর ভ্যাট ধরে |
| ⏳ পূর্বাভাস | ব্যালেন্স কত দিন চলবে, কবে শেষ হবে, মাস শেষে বিল কত হবে |
| 🔔 অ্যালার্ট | কম ব্যালেন্স, ৩ দিনের কম বাকি, অস্বাভাবিক খরচ (গড়ের ১.৫ গুণ), বাজেট পার, রিচার্জ সফল |
| 🌅 দৈনিক রিপোর্ট | প্রতিদিন সকাল ৯টায় টেলিগ্রামে সারাংশ |
| 💡 সাশ্রয়ের টিপস | আপনার ডেটা দেখে পরামর্শ দেয় (যেমন পরের দামি স্ল্যাবে ওঠার আগে সতর্ক করে) |

## চালানোর নিয়ম
```bash
pip install -r requirements.txt
cp .env.example .env        # তারপর .env এডিট করুন
python check.py             # মিটার কানেকশন টেস্ট
python run.py               # http://localhost:8000
```

আসল মিটার বা API key ছাড়াই পুরো অ্যাপ দেখতে চাইলে:
```bash
python check.py --demo
PROVIDER=demo python run.py
```
ডেমো মোডে ১২০ দিনের বাস্তবসম্মত ডেটা, রিচার্জ হিস্ট্রি, সিমুলেটেড লাইভ লোড আর একটা ইচ্ছাকৃত খরচ-স্পাইক থাকে — তাই অ্যালার্ট, গ্রাফ আর AI সবই কাজ করতে দেখা যায়।

### .env-এ মূল সেটিংস
```ini
PROVIDER=desco              # desco | dpdc | demo  (.env.example-এ ডিফল্ট demo)
ACCOUNT_NO=12345678         # DESCO Account No. / DPDC Customer No.
SANCTION_LOAD_KW=2          # অনুমোদিত লোড (বিলে লেখা থাকে)
LOW_BALANCE_TK=300
MONTHLY_BUDGET_TK=2500
```

বাকি সব অপশন (ক্রিটিক্যাল সীমা, পোলিং বিরতি, রিপোর্টের সময়, টাইমজোন) `.env.example`-এ বাংলা কমেন্টসহ আছে।

### AI চালু করা (ঐচ্ছিক)
API key না দিলেও বিল্ট-ইন বাংলা এজেন্ট কাজ করে। আরও স্বাভাবিক কথোপকথন চাইলে যেকোনো OpenAI-compatible API দিন। Google Gemini-র ফ্রি টায়ার দিয়ে শুরু করা যায়:
```ini
LLM_API_KEY=আপনার_key       # https://aistudio.google.com/apikey
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
LLM_MODEL=gemini-2.5-flash
```
LLM টুল-কলিং দিয়ে আসল ডেটা পড়ে (ব্যালেন্স, ব্যবহার, বিল, রিচার্জ, ট্যারিফ, টিপস) — সংখ্যা নিজে বানায় না। LLM কোনো কারণে ব্যর্থ হলে (নেটওয়ার্ক, কোটা, ভুল key) উত্তরটা স্বয়ংক্রিয়ভাবে বিল্ট-ইন এজেন্ট দিয়ে আসে, আর UI-তে ইঞ্জিনের নাম দেখায়।

### টেলিগ্রাম বট
1. টেলিগ্রামে **@BotFather**-কে `/newbot` পাঠান। যে টোকেন পাবেন সেটা `TELEGRAM_BOT_TOKEN`-এ দিন।
2. সার্ভার চালু করে বটকে `/id` পাঠান। উত্তরে যে নম্বর আসবে সেটা `TELEGRAM_CHAT_IDS`-এ দিন, তারপর রিস্টার্ট করুন।
3. কমান্ড: `/balance` `/today` `/bill` `/days` `/tips` `/recharge` `/monthly` `/tariff` `/live`। চাইলে সরাসরি প্রশ্নও লিখতে পারেন।

বট লং পোলিং ব্যবহার করে, তাই webhook বা পাবলিক URL লাগে না। `TELEGRAM_CHAT_IDS` খালি থাকলে কাউকে মেসেজ যায় না — `/id` কমান্ড তখনও কাজ করে, যাতে নিজের নম্বরটা বের করা যায়।

## "রিয়েল-টাইম" নিয়ে একটা জরুরি কথা ⚠️
DESCO/DPDC-র সার্ভার প্রিপেইড মিটারের ডেটা **সাধারণত দিনে একবার** আপডেট করে। এজেন্ট প্রতি ৩০ মিনিটে ব্যালেন্স চেক করে, আর নতুন রিডিং এলে সাথে সাথে ধরে ফেলে। তবে এই মুহূর্তে কত ওয়াট টানছে, সেটা ইউটিলিটির API দেয় না।
সেকেন্ড-বাই-সেকেন্ড লোড দেখতে চাইলে **ESP32 + PZEM-004T** সেন্সর (খরচ ~১৫০০–২০০০ টাকা) লাগাতে হবে। কোডে আলাদা প্রোভাইডার সিস্টেম আছে, তাই সেন্সর যোগ করলে বাকি সব (ড্যাশবোর্ড, AI, অ্যালার্ট) একই থাকবে। ডেমো মোডে লাইভ গ্রাফটা দেখতে কেমন হবে তা দেখা যায়।

## হিসাব কীভাবে হয়
**বিল** — স্ল্যাবভিত্তিক এনার্জি চার্জ + ডিমান্ড চার্জ (৳৪২/কিলোওয়াট) + মিটার ভাড়া − প্রিপেইড রিবেট + ৫% ভ্যাট। "এই মাসে এ পর্যন্ত" দেখানোর সময় ডিমান্ড চার্জ আর মিটার ভাড়া মাসের যত দিন গেছে সেই অনুপাতে ধরা হয়।

**পূর্বাভাস** — শেষ ৭ ও ৩০ দিনের গড়ের ওয়েটেড মিশ্রণ (৬০/৪০) নিয়ে দৈনিক ইউনিট বের করা হয়, তারপর বর্তমান স্ল্যাবের রেট দিয়ে দৈনিক টাকা। `ব্যালেন্স ÷ দৈনিক খরচ` = কত দিন চলবে। সিদ্ধান্তটা "marginal rate" দিয়ে হয়, কারণ পরের ইউনিটের দামই এখন প্রাসঙ্গিক।

**অস্বাভাবিক খরচ** — সর্বশেষ দিনের ব্যবহার আগের ১৪ দিনের গড়ের সাথে তুলনা করা হয়; `ANOMALY_MULTIPLIER` (ডিফল্ট ১.৫) গুণের বেশি হলে অ্যালার্ট।

**ডেটা না এলে** — ইউটিলিটি সার্ভার বন্ধ থাকলে বা API বদলে গেলে শেষ সফল স্ন্যাপশট (`data/snapshot.json`) দিয়েই ড্যাশবোর্ড চলে, আর "রিডিং পুরনো" / "ডেটা আসছে না" অ্যালার্ট ওঠে। সার্ভার ক্র্যাশ করে না।

## REST API
| এন্ডপয়েন্ট | কাজ |
|---|---|
| `GET /api/dashboard` | ড্যাশবোর্ডের পুরো পেলোড (`?force=true` ক্যাশ বাদ দিয়ে) |
| `POST /api/refresh` | জোর করে নতুন ডেটা এনে ড্যাশবোর্ড ফেরত |
| `GET /api/status` | সংক্ষিপ্ত অবস্থা + অ্যালার্ট |
| `GET /api/usage?days=30` | দিনভিত্তিক সিরিজ |
| `GET /api/bill?units=250` | নির্দিষ্ট ইউনিটের বিল ভাঙা হিসাব |
| `GET /api/forecast` | পূর্বাভাস |
| `GET /api/tariff` | ট্যারিফ স্ল্যাব |
| `GET /api/alerts` | সক্রিয় অ্যালার্ট |
| `GET /api/recharges?limit=10` | রিচার্জ হিস্ট্রি |
| `GET /api/history?days=60` | জমে থাকা দিনভিত্তিক ডেটা |
| `GET /api/live` | লাইভ লোড (সেন্সর/ডেমো থাকলে) |
| `POST /api/chat` | `{"message": "..."}` → এজেন্টের উত্তর |
| `POST /api/check?send=false` | একবার পোলিং + অ্যালার্ট মূল্যায়ন |
| `GET /api/config` | UI-এর সেটিংস (কোনো গোপন কী নেই) |
| `GET /api/health` | হেলথ চেক |

Interactive docs: `http://localhost:8000/docs`

## সমস্যা হলে
| সমস্যা | সমাধান |
|---|---|
| `python check.py`-তে ৫০৩ / "ডেটা পাওয়া যায়নি" | DESCO/DPDC পোর্টালের API অফিসিয়াল নয়, মাঝে মাঝে বদলায় বা IP ব্লক করে। `python run.py` চালিয়ে `PROVIDER=demo` দিয়ে অ্যাপ দেখুন; `app/providers/desco.py`-তে পাথ ঠিক করতে হবে |
| ড্যাশবোর্ডে "রিডিং পুরনো" | স্বাভাবিক — ইউটিলিটি দিনে একবার আপডেট করে। `STALE_AFTER_MINUTES` দিয়ে সীমা বদলান |
| টেলিগ্রামে কিছু আসছে না | `TELEGRAM_CHAT_IDS` সেট আছে কি না দেখুন; বটকে `/id` পাঠান; টোকেন ভুল হলে লগে 401 দেখাবে |
| AI ইংরেজিতে/অদ্ভুত উত্তর দিচ্ছে | `LLM_MODEL` আর `LLM_BASE_URL` মিলছে কি না দেখুন; key না থাকলে অফলাইন এজেন্ট চলবে |
| বিলের অঙ্ক মিলছে না | `tariff.json`-এ আপনার এলাকার (DESCO/DPDC) সর্বশেষ BERC আদেশের রেট বসান — ডিমান্ড চার্জ, মিটার ভাড়া, রিবেট এলাকা ভেদে আলাদা |
| `data/` ফোল্ডার তৈরি হচ্ছে | এটাই ক্যাশ/হিস্ট্রি; রিসেট করতে ফোল্ডারটা মুছে দিন, অ্যাপ আবার বানাবে |

## সতর্কতা
- DESCO/DPDC-র এই API গুলো অফিসিয়াল ডকুমেন্টেড না, এগুলো তাদের নিজেদের পোর্টাল/অ্যাপ ব্যবহার করে। পরে বদলে যেতে পারে। কোডে রেসপন্স পার্সারটা নমনীয় রাখা হয়েছে — ফিল্ডের নাম একটু বদলালেও চলে, তবে বড় পরিবর্তনে `app/providers/desco.py` বা `dpdc.py`-তে পাথ/কী ঠিক করতে হবে।
- ড্যাশবোর্ডে আপনার নাম-ঠিকানা দেখায়। তাই সার্ভারটা পাবলিক ইন্টারনেটে খোলা রাখবেন না।
- মিটার ভাড়া আর প্রিপেইড রিবেট এলাকা ভেদে আলাদা হতে পারে। দরকার হলে `tariff.json`-এ ঠিক করে নিন।
- `data/` আর `.env` গিটে যায় না (`.gitignore`-এ আছে) — আপনার টোকেন/key কারো সাথে শেয়ার করবেন না।
